# Plan

Keep Pydantic AI in charge of model calls and authorization protocol. Add `src/atbots/auth.py` for CLI-facing flows, keyring credential source, non-secret profile status and per-profile process locks; no token scraping from CLI homes. Add `providers/authenticated.py` as thin model construction wiring reusing the shared `PydanticAIProvider._build_agent` factory, not another agent or transport. ChatGPT uses native `OpenAIChatGPTOAuthFlow`, `OpenAIChatGPTProvider`, credential source and Responses model; GitHub uses native `GitHubCopilotOAuthFlow`, provider and model with a user-configured OAuth app client ID. Native Anthropic uses its API key only. Pin the auth extra to the verified upstream feature floor and make imports lazy.

Credential service is AtBots-specific, account keys are provider/profile; only a provider allowlist and bounded profile names enter it. Native keyring backends only, not plaintext/chainer fallbacks. `filelock` serializes full inference/refresh and login/logout on the same profile lock. Store access/refresh credentials as secret JSON in keyring and nonsecret flags derived on read; do not persist them in config. Refresh storage failures stop the call with redacted recovery instructions. An asyncio timeout bounds asynchronous authorization; OS keychain dialogs remain platform-controlled. No credentials are read by import/constructor. Unknown provider selection does not silently succeed.

Extend `ProviderConfig` additively (`auth_profile`) and wire CLI auth before legacy companion initialization. Remote provider kinds must explicitly declare remote egress. Preserve existing Ollama routing; unavailable selected subscription providers raise a redacted error for requested remote selection rather than fake a local answer. Existing local deterministic behavior is otherwise unchanged. Existing companion/core-memory constitution drift is preexisting, outside this authentication slice, not fixed or certified here.

Test with mocked upstream OAuth and HTTP plus fake credential backend, no real accounts or provider fees. Build artifacts and verify imports/CLI from a wheel. macOS local tests are real; Windows/Linux locking uses the cross-platform dependency but live platform/keychain acceptance must not be claimed without those hosts. Preserve user `evals/baseline.json`. Do not publish or commit automatically.
